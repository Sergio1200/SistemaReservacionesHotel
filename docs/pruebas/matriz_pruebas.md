# Matriz de pruebas de la etapa 11

La ejecución usó datos ficticios en H2 o en una instancia aislada de MySQL 8.0.46. La letra **E** identifica recorridos automatizados en Edge. La letra **A** identifica pruebas JUnit y MockMvc. **V** identifica la revisión visual de las capturas y **D** la inspección directa del esquema y los registros de MySQL.

El flujo principal consultó primero un intervalo futuro. Para completar el check-in en la misma sesión de pruebas, la estancia ficticia empezó el día local del hotel. Edge realizó las operaciones de los tres roles mediante los formularios de la aplicación. Las consultas de MySQL se usaron para comprobar el resultado de esas operaciones sin cambiar el reloj ni la base habitual.

Las capturas omiten las credenciales y los datos académicos personales. La evidencia de tableta encuadra los dos logotipos y el encabezado de «Acerca del proyecto».
